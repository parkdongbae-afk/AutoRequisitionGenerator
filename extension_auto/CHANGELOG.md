# 변경 내역

## v18.1.0

- Edge 폴더 선택창의 `폴더:` 입력칸(`automation_id=1152`)에 대상 경로 직접 입력
- `폴더 선택` 버튼(`automation_id=1`) 우선 클릭
- 별도 최상위 창과 브라우저 하위 Window 형태의 폴더 선택창 모두 탐색
- 기존에 열려 있던 마지막 익스텐션 경로가 선택되는 문제 수정
- 폴더 선택창이 첫 클릭에 경로 이동만 하는 경우 두 번째 선택 시도 추가
- 실패 메시지에 실제 자동 입력 대상 경로 표시


## v18.0.0

- 압축 해제된 익스텐션 폴더 선택 UI 추가
- 선택한 브라우저 프로필에 개발자 모드를 켠 뒤 익스텐션을 자동으로 로드하는 작업 추가
- Chrome/Edge/Whale의 `Load unpacked` 버튼 탐색 추가
- Windows 폴더 선택창 자동 입력 및 선택 추가
- manifest.json 사전 검증 추가
- 마지막 익스텐션 경로 저장 추가
- 권한 없는 Manifest V3 테스트 익스텐션 포함
- PyInstaller onefile 실행 시 테스트 익스텐션을 APPDATA 영구 폴더로 복사
- EXE 빌드 스크립트에 테스트 익스텐션 리소스 포함

[원클릭 연동 - 권장]

앱 헤더의 [🌐 브라우저 원클릭 연동] 버튼을 한 번만 클릭하면:
1. 설치된 Edge/웨일(및 지원 버전 Chrome) 감지 → 바탕화면에 "브라우저명 - 품의 캡처" 바로가기 자동 생성
   (해당 바로가기로 브라우저를 시작하면 확장 프로그램이 자동 적용됩니다)
2. 북마크릿 설치 페이지가 자동으로 열립니다 (모든 브라우저 공용)
   - 파란 [🛒품의캡처] 버튼을 북마크바로 드래그
   - 주문 화면에서 클릭 한 번 → 앱으로 전송

[주의]
- 최신 Chrome(stable, v137 이상)은 정책상 --load-extension 자동 적용이 차단됩니다 → 북마크릿 방식 사용
- 바로가기 방식은 브라우저가 완전히 종료된 상태에서 시작해야 확장이 적용됩니다 (이미 실행 중이면 일반 창만 열림)
- 앱이 실행 중이어야 전송이 동작합니다 (로컬 127.0.0.1:57330~57335 수신)

[수동 설치 - 기존 방법]
1. Chrome/Edge/웨일 주소창에 chrome://extensions (edge://extensions, whale://extensions) 입력
2. 오른쪽 상단 '개발자 모드' 활성화
3. '압축해제된 확장 프로그램 로드' → 이 폴더(extension) 선택
